# [ADR-002]：[作るもののイメージ固め]

## ステータス
提案中

## 背景
- 課題：
    - 案件検索基盤はやろうと思えば何でもできるし活用法も多数
    - だからこそ目指すビジョンを明確にしないと目的がぶれそう
- 制約：
    - 上からの圧力であれやれこれやれが発生する可能性が無きにしも非ず

## 意思決定
- 「キャリア実現性」向上を目指し、現状最も不満が大きい情報の不透明さを解消するため、案件情報という事実の開示を最優先とする
- そのため「どういう案件があるのか」の事実を網羅的・横断的に共有することを第一とする
- つくらないものとして「ジュニアが入れるかどうか」「今入れる案件かどうか」「技術スタックのマッチ度算出」など、検索結果を使用した機能は最初は作らない

## 結果・影響
- メリット：
    - 検索基盤構築にコミット可能
- リスク/負債：
    - 後々機能開発できる拡張性は考える必要がある
- 影響：
    - 関わる人たちに周知しないと方向性ぶれる
