# [ADR-0001]：[Phase1: まずは検索基盤構築を進める]

## ステータス
提案中

## 背景
- 課題：
    - やりたいことの全体像は大まかに描けた([こちら参照](/docs/vision.md))が、やりたいことがAXでありビジネス構造の変革を伴う
    - 相談が必須なステークホルダーが多く、動ける範囲に限界がある
    - そもそもデータが整っているのか・リソース使えるのか・セキュリティ要件どうなっているのか等不明点が多い
- 制約：
    - 何事においても意思決定権が作成者にない
    - 会社が持つLLM API利用権は誰が持つか不明
    - 会社が持つクラウドリソース利用権は誰が持つか不明
    - 誰を巻き込めば全社にシステム導入できるか不明

## 意思決定
- AX実現ができず既存のフローのままになった時でも、必ず会社のためになる案件検索基盤の構築を先に進めることを決定
    - これをPhase1とする
    - PRDは[こちら](/docs/prd/prd-search-engine.md)
    - いきなり構築するのではなく、下記ヒアリングのためにも設計をある程度固める予定
- 並行して、制約を解消できるよう営業部署・経営層・情シス・IVT業務一覧作成者・AMBL Chat作成者等有権者にヒアリングを実施する
    - 上記制約の解消が求められるので、誰がキーマンかを明確にする必要があるため
- 大まかなプロジェクトフェーズは下記を検討
    - Phase1: 検索基盤構築
    - Phase2: 案件マッチングスコア出力エージェント等オーケストレーションシステム構築
    - Phase3: ビジネス構造を変革し案件アサインフローAXを実現

## 結果・影響
- メリット：
    - PoCとしての効果もあり、各所への相談がしやすくなる
- リスク/負債：
    - 全社展開が保証されているわけではないため、つくったが無駄になったということが発生しうる
    - 全員役職者であり忙しいため、ヒアリング内容の精査が必須
- 影響：
    - 特になし
