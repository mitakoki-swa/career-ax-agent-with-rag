## 1. プロジェクト概要
本プロジェクトは、案件マッチングAIを構築し、案件アサインフローをAXする取り組みである<br>

ここでいうAXとは、単に既存業務にAIを部分導入することではなく、AIを活用して業務フロー・情報共有・役割分担・意思決定プロセスを再整理し、より生産性の高い業務構造へ変革することを指す

本プロジェクトでは、以下3点の実現を目指す。

1. 案件情報の透明化
<br>案件情報を整理・構造化し、エンジニアがキャリア選択に必要な情報へアクセスしやすい状態をつくる<br>
顧客情報・単価・商流・営業メモなどの機密性が高い情報については、必要に応じて権限設計やマスキングを前提とする

2. アサイン判断材料の可視化
<br>案件要件、必要スキル、必要経験、参画可能性、補完すべき要素をAIによって整理・可視化する<br>
AIは最終的なアサイン可否を決定するものではなく、マネージャーや営業が判断するための材料を整える役割を担う

3. 専門性を活かした分業の徹底
<br>エンジニア、マネージャー、営業がそれぞれ本来注力すべき役割に集中できる状態をつくる
<br>　・ エンジニア：案件探索・キャリア希望の整理・参画希望の提示
<br>　・マネージャー：参画可否判断・育成判断・社内調整
<br>　・営業：顧客折衝・案件獲得・単価向上・提案活動
